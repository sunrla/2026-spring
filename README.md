# SkinLoop

SkinLoop은 스킨케어 루틴, 사용 제품, 전성분, 주간 피부 기록을 바탕으로 루틴을 관찰하고 조정할 수 있게 돕는 기말 프로젝트입니다.

## 웹앱 실행 링크

https://sunrla.github.io/2026-spring/

## 최종 프로젝트 위치

`apps/skinloop`

## 주요 기능

- 피부 프로필 설문
- 제품 등록
- 제품명 검색 및 자동 입력
- 전성분 파싱
- 성분 태그 설명
- 루틴 위험도 참고
- 입력 기반 루틴 추천
- 주간 피부 기록
- 대시보드
- 브랜드/관리자 인사이트
- 데모 데이터 채우기

## 실행 방법

```bash
cd apps/skinloop
npm install
npm run dev
